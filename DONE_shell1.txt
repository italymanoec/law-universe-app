LEXO shell-1 / v79-shell-1（2026-10-23，Claude Code 接手 Codex 工單）

一句話：把 LEXO 改成像手機 App 的樣子——上面一條 LEXO 標題列，下面固定四個分頁（首頁・申論・刷題・地圖），每頁只有一顆黑色大按鈕在拇指按得到的位置；不用任何手勢，也不用看說明。

修改清單
1. 外框（app/index.html、app/pwa/lexo.css，整個重寫）
   - 頂部 52px 標題列：左邊「←」（分頁首頁不顯示），中間 LEXO（名稱取自設定常數）。
   - 底部固定 4 個分頁，每個都有圖示和文字：首頁／申論／刷題／地圖；目前所在分頁變黑加粗。正在看的分頁再點一次＝捲回頂端。
   - 每頁只有一顆主要按鈕：黑底白字、高 56px、寬滿版，固定在分頁列正上方（360x780 時 y=648–704，離底 76px）。
   - 桌機：整個 App 置中、最寬 480px，左右灰底，看起來就是一支手機。
2. 操作方式（app/vendor/lexo.js，新寫）：一步一步走，畫面上看得到的按鈕或列表就是全部能做的事。
   - 首頁：大按鈕「開始第一題」；有看過的話下面多一張「上次看到」卡片；今天刷了幾題；免責聲明只出現一次；最下面「舊版」連到 /classic/。
   - 申論：選科目（民法總則／物權／刑法總則）→ 題目大卡片列表（年份・題號・分數、標題、幾個關鍵問題・幾條法條、看過標記）→ 題目頁 → 「下一題」。
   - 題目頁由上往下排：這題在問什麼（黑底卡片）→ 題目原文（按一下展開）→ 爭點（關鍵問題），每個爭點下面列出「要用到的法條」「可能也會用到」的法條按鈕 → 要用到的法條（點開看條文，裡面列出「其他也考這條的題目」和「看這條的完整說明」）→ 一起考的法條（可點進去看這組法條）。
   - 法條頁：條文、要件（成立條件）、常見爭點（關鍵問題）、法院怎麼說（判決摘要和原文連結；沒有就寫還沒找到）、用到這條的題目（列表）、相關法條、全國法規資料庫連結。從題目點進來時，主要按鈕是「下一條法條」，最後一條變成「回到這題」。
   - 刷題：錯題本（有錯題才出現）＋16 科列表（含題數）→ 一次一題。選擇題點選項後立刻顯示答對／答錯、正確答案、解析，主要按鈕變「下一題」；申論式題目（例如財稅法）是「看參考答案」→ 答題要點＋參考答案 →「我寫得出來／我還不會」→「下一題」。順序沿用原本的複習間隔：到期該複習的先出，再出新題。
   - 錯題本：列出所有答錯過的題目（答錯越多次排越前面），可以點其中一題，或按「從第一題開始重做」。
   - 作答紀錄沿用原本的 localStorage 鍵 civil-globe-v2，欄位一樣（srs b/d/w/t、每日 log），舊紀錄和錯題都還在。
   - 回上一頁：左上角「←」和瀏覽器上一頁都能用。直接打開某一頁的連結時，← 會回到 App 裡的上一層（例如法條頁→申論），不會跳出網站。
3. 地圖（取代原本的蜂巢）：只用來看全貌和常考程度。
   - 上方四顆按鈕切換：民法總則／物權／刑法總則／全部。
   - 「題目」一區（藍色格子）和「法條」一區（灰階，顏色越深越常考：考 1 題／2 題／3 題以上），格子裡寫條號和考了幾題。
   - 每一格都是連結：題目格直接開題目頁，法條格直接開法條頁，不會原地換中心。
   - 格子依畫面寬度排成蜂巢列，往下排、不往左右超出；360／390／桌機三種寬度下全部 92 格都在畫面內。
   - 拿掉拖曳、縮放、點格子換中心、上一步、下一組關聯。
4. 拿掉的東西：五關新手教學、說明卡、進度條教學、科目解鎖（全部開放）、3D 地球、舊版蜂巢。畫面上不出現「節點」「組合包」「反查」「爭點節點」；用到「爭點」「要件」的地方旁邊加白話（關鍵問題）（成立條件）。
5. 名稱：vendor/app-config.js 的 LAWU_CONFIG.name = 'LEXO' 是唯一的設定常數；App 標題列和分頁標題在執行時讀這個常數。tools/finalize-shell.py 會把常數寫進靜態的 <title>、apple-mobile-web-app-title、標題列和 manifest，所以頁面原始碼不再有 {{APP_NAME}}（抓網址預覽、iOS 加入主畫面、不開 JS 也都看到 LEXO）。
6. essay.html 改成轉址頁：舊連結 essay.html#article/<條號> → 法條頁，#mindmap → 地圖，其他 → 申論。
7. 移到 ~/law-universe-essay/app_retired_20261023_shell1/（不刪檔，新版不再載入）：vendor/three.min.js、THREE-LICENSE.txt、journey.js、mindmap.js、pwa/paper.css、pwa.css、pwa-boot.js。Service worker 註冊和「有新版本，點這裡更新」改寫在 lexo.js 裡。
