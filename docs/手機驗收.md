# 手機驗收（headless Chrome）

日期：2026-10-31。對象：`dark/`（法學記憶宇宙）。補上 `dark/DONE.txt` 寫的「尚無真實手機版面、飛航重開驗收」。

這次**沒有改程式、題目、答案、條文、配色**。只記錄 headless Chrome 裡實際看到的畫面。不是 iPhone／Android 實機，也沒有做主畫面安裝。

## 怎麼跑

- Chrome 156.0.8078.47，`--headless`，`--enable-unsafe-swiftshader`（要有 WebGL，星圖才畫得出來）。
- 本機靜態站：`http://127.0.0.1:8765/dark/`（`python3 -m http.server`）。localhost 算安全來源，service worker 可以註冊。
- 視窗：390×844、360×800，`deviceScaleFactor: 2`，手機 UA，觸控點擊（`touchscreen.tap`）。
- 環境沒有安裝 Noto Sans TC。中文落到文泉驛微米黑／Droid Sans Fallback。換行位置可能和手機上的 Noto 有一點差；下面寫的「被鈕蓋住」是黏底按鈕疊在內容上，不靠字型。
- 每個尺寸各開一個新的瀏覽器內容（localStorage、service worker 分開）。
- 監聽 `console` error／warning、`pageerror`、`requestfailed`。兩種尺寸、連線與離線重開，這三類都是 **0 筆**。

複選題沒有出現在「今日刷題」的第一題（第一題是 115 年民法第 1 題，單選）。複選改走畫面上的路徑：目錄 →「法律行為之無效與暴利」→ 相關題 105 年第 63 題。

## 複選送出：通過，未捲動時最後一項會被擋住

步驟：

1. 關閉題目面板。
2. 「目錄」→「法律行為之無效與暴利」。
3. 相關題點 105 年第 63 題。
4. 標題出現「複選題」。未選時「送出答案（已選 0 項）」是停用的。

## 離線重開：通過（瀏覽器斷網）

連線時先等到 service worker 控制頁面，狀態是「離線題庫已備妥 · 作答紀錄存本機」。快取名稱 `lawu-http%3A%2F%2F127.0.0.1%3A8765%2Fdark%2F-db-26451b3139`，35 個檔，含 `index.html`、`qb/civil.js`、`qb/administrative.js`。此時 localStorage `civil-globe-v2` 裡有 2 筆作答。

然後關掉該分頁，新開一頁，**先設離線再打開同一個網址**（`navigator.onLine === false`）。

兩種寬度都是 HTTP 200，沒有 Chrome 的斷線錯誤頁。

重開後看到：

- 「離線可用」
- 「錯題 2」「已刷 2 題」（作答紀錄還在）
- 「繼續讀：民法§801 ›」（前面搜尋點開過這條）
- 點「錯題 2」再開到 105 年第 63 題，仍寫「答錯過 1 次」
- 再點「切換科目」→ 行政法。離線下標題變成「行政法記憶星球」，副標「307 題真題」，不是「題庫載入失敗」

## 看到的錯誤

### 1. 黏底「送出答案」蓋住最後一個選項（字被切掉，選項正中心點不到）

兩種寬度都有。面板裡的「送出答案」是黏在可視區底部的。內容還沒捲到最底時，它會壓在最後幾個選項上。

重現：

1. 390×844 或 360×800 打開 `http://127.0.0.1:8765/dark/`。
2. 目錄 → 法律行為之無效與暴利 → 105 年第 63 題。
3. 不要先把題目面板捲到最底。

390×844，捲動在最上面時量到：

- (E) 高 115px，約 50px 被送出鈕蓋住，露出約 61px。截圖上文字停在「因屬權利」，後面的「濫用，法院據此應減少價金，甚或命免支付」被鈕蓋住。
- 點 (E) 的正中心，點到的是「送出答案」，不是選項。
- 面板還能再捲 96px。捲到最底後 (E) 整段露出（高 115px，不再被蓋），點下去會變成已選。見 [390 捲到底](手機驗收/390x844-04b-複選捲到底.png)。

360×800，捲動在最上面時量到：

- (E) 完全在面板可視區外面（露出高度 0）。
- (D) 高 86px，約 50px 被送出鈕蓋住，只剩約 36px。已勾選那張圖上，「有理由」的「由」被切在鈕的上緣。見 [360 已勾選](手機驗收/360x800-05-複選已勾選.png)。
- 捲到最底（還能捲 215px）後 (D)(E) 都完整，(E) 點得到。見 [360 捲到底](手機驗收/360x800-04b-複選捲到底.png)。

送出之後的「看本輪結果」也是同一種黏底鈕。360 的送出結果截圖裡，解析最後一行被這個鈕蓋住，只露出下一行的上緣。見 [360 送出](手機驗收/360x800-06-複選送出.png)。這張圖是把「答錯」捲到中間時拍的。選項在捲到最底後可以露出，解析應可再往下捲，這次沒有另拍「解析捲到最底」的圖。

### 2. 搜尋結果的題目列被省略號截斷

重現：任一寬度，搜尋框輸入「善意取得」。

題目列用單行省略。390 畫面上看得到的結尾是：

- 「115年 甲將乙所寄放市價新臺幣（下同）4000元...」
- 「113年 甲畫家受監護宣告，在心智清醒時，將代...」

點第一筆「民法 §801」有打開條文（第 801 條全文在條文面板裡）。見 [390 搜尋](手機驗收/390x844-07b-搜尋.png)、[點開條文](手機驗收/390x844-07c-搜尋點擊後.png)，360 對應 [搜尋](手機驗收/360x800-07b-搜尋.png)、[點開條文](手機驗收/360x800-07c-搜尋點擊後.png)。

清單最底下還有「全部 13 題 → 刷題」。第一屏看不到它，命中測試時那個位置點到的是後面的星圖。清單本身可以捲，這次**沒有**再把清單捲下去點那顆鈕，所以不能寫成「一定點不到」。

搜尋清單打開時會蓋住「今日刷題」「錯題」「章節」。關掉清單之後，這些鈕在前面的流程裡都點得到。

### 3. 條文面板的修法條號鈕又小又貼邊

從搜尋點進民法 §801 之後，「本法另有修法或違憲備註」裡的條號鈕實測：

- §1223 約 38×25px
- §166-1 約 42×25px
- §1052 約 38×25px

截圖裡 §1052 貼在虛線框下緣，看起來被框切到。見 [390 條文](手機驗收/390x844-07c-搜尋點擊後.png)。這次沒有去點這三個條號，所以只記尺寸和看起來被切，不記成「點了沒反應」。

### 4. 「繼續讀」蓋住星圖上的考點名

離線重開後，畫面中間有「繼續讀：民法§801 ›」。它蓋在星圖上，390 那張圖右側考點名只剩半個「善意義務」一類的字。星圖標籤本來就會轉出螢幕外；這裡是浮在上面的鈕額外遮住。見 [390 離線重開](手機驗收/390x844-08-離線重開.png)。

- iPhone／Android 實機、加入主畫面、系統飛航模式：這台環境只有 headless Chrome，沒有實機。
- 今日刷題 8 題沒有全部答完：第 1 題點 (D) 已經得到錯題，後面改去測複選。

- 搜尋清單的「全部 13 題 → 刷題」：第一屏在清單外，沒有捲下去點。
- 其餘 14 科沒有逐科開題。離線只多開了行政法，確認題庫數字會出來。
